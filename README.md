## Описание компонентов

### 1. API-шлюз (`cmd/api-gateway`)
- Прием запросов от интернет-магазинов
- Первичная аутентификация мерчантов
- Маршрутизация запросов к внутренним сервисам
- Возврат ответов клиенту

### 2. Модуль валидации (`cmd/validator`)
- Проверка корректности входных данных
- Валидация сумм, валют, форматов карт
- Проверка обязательных полей

### 3. Оркестратор платежей (`cmd/orchestrator`)
Центральный компонент с 5 контейнерами:
- **Менеджер состояния** - хранение текущего статуса транзакции
- **Маршрутизатор** - выбор адаптера платежной системы
- **Рабочие процессы** - управление жизненным циклом транзакции
- **Обработчик повторных попыток** - ретрай неудачных транзакций
- **Обработчик обратных вызовов** - обработка ответов от ЭПС

### 4. Антифрод (`cmd/antifraud`)
- Анализ транзакций на мошенничество
- Проверка паттернов поведения
- Оценка рисков

### 5. Модуль токенизации (`cmd/tokenizer`)
- Преобразование чувствительных данных в токены
- Безопасное хранение данных карт

### 6. Адаптер платежной системы (`cmd/adapter`)
- Интеграция с внешними ЭПС (СБП, банки, цифровой рубль)
- Преобразование форматов данных
- Обработка ответов от платежных систем

### 7. Сервис уведомлений (`cmd/notification`)
- Отправка результатов транзакций
- Webhook уведомления мерчантам
- Email/SMS уведомления

### 8. Модуль логирования (`cmd/logger`)
- Сбор всех событий системы
- Аудит транзакций
- Логирование ошибок

### 9. База данных (PostgreSQL)
- Хранение транзакций
- Хранение токенов
- Логи и аудит

## Технологии

- **Язык**: Go 1.21+
- **Фреймворк**: go-kit (микросервисная архитектура)
- **База данных**: PostgreSQL 15+
- **Миграции**: golang-migrate
- **Контейнеризация**: Docker, Docker Compose
- **Тестирование**: testify, gomock

## Быстрый старт

```bash
# Установка зависимостей
go mod tidy

# Запуск через Docker Compose
docker-compose up -d

# Запуск миграций
make migrate-up

# Запуск всех сервисов
make run-all
```
